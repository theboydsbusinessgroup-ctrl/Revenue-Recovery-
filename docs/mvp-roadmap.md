# MVP Roadmap

## Phase 1 — Foundation
- Domain entities and state machine
- Opportunity scoring
- Compliance/suppression model
- Recovery event ledger
- Telemetry contract
- Test fixtures for quote reactivation

## Phase 2 — First usable workflow
- CSV/manual export ingestion for zero-cost pilot
- Candidate detection
- Scoring and recovery queue
- Approved message templates
- Reply classification interface
- Attribution and reconciliation
- Client report

## Phase 3 — Automation
- Authorized CRM connectors
- Messaging provider integration
- Scheduled detection/recovery jobs
- Automated reporting
- Failure/retry handling
- JARVIS telemetry adapter

## Phase 4 — Commercial validation
- 3–5 pilot businesses
- Performance-based contracts
- Measure recovered dollars, not activity
- Establish minimum viable recovery rate and unit economics
- Retain only profitable verticals/workflows

## Phase 5 — Scale
- Vertical configurations
- Self-serve onboarding
- Multi-tenant controls
- Automated billing
- Portfolio optimization through JARVIS

## First-revenue rule

Do not wait for the complete autonomous platform. The first commercial test should use the smallest compliant workflow capable of proving that dormant opportunities can be converted into attributable revenue.
